# Salon Lumière — 美容室サイト制作サンプル

架空の個人サロンを想定した自主制作。HTML / CSS / JavaScriptのみで構成し、ビルド不要でGitHub Pagesに公開できます。

## 制作の意図

- 想定するお客様：落ち着いた空間と、自宅で扱いやすい髪型を求める方。
- 店内のイメージからコンセプト、料金、スタイル、FAQ、アクセスへ進む構成。
- スマートフォンでは画面下部から予約デモを開けます。
- 予約デモはメニュー別の時間・料金確認まで。入力情報の送信・保存・実際の予約は行いません。
- キーボード操作、フォーカス表示、モーション軽減設定に配慮しています。

## プレビュー・公開

`index.html`をブラウザで開いて確認できます。公開時はこのディレクトリの内容を公開リポジトリへ配置し、Settings → Pages → Deploy from a branch → main / (root) を設定します。

## 公開前の確認

- PCとスマートフォンで、写真・文字の折り返し・メニュー・予約デモ・外部地図リンクを確認。
- 架空案件の表示を維持し、営業先にも「自主制作」と明記。
- SNS共有用の `og:image` と `og:url` は公開URL確定後に絶対URLで追加。
- 本案件へ流用するときは実際の情報・写真・予約リンクへ置換。

## 検証

Edgeのヘッドレス表示でスマートフォン幅320px・390pxと、タブレット・PC幅を確認。画像読み込み、横方向のはみ出し、ページ内リンク、メニュー開閉、予約ダイアログ、カラー料金の切り替え、確認画面、選び直し、FAQ、ダイアログ終了後のスクロールとフォーカス復帰を検証しました。JavaScriptの構文とローカルファイル参照も確認済みです。iPhone・Androidの実機確認は未実施です。
